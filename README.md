# Umělá inteligence v praxi

Webová prezentace Jana Kudrny, 42 slajdů. Zachovává logo a černozlatý vizuální základ původní prezentace.

## Ovládání

- Šipky vlevo a vpravo: předchozí a další slajd.
- `F`: celá obrazovka.
- `G`: přehled slajdů s vyhledáváním.
- Kliknutí na obrázek: zvětšení.
- `Esc`: zavření přehledu nebo zvětšení.

## Spuštění a aktualizace

Prezentace je v jediném souboru `index.html`. Obsahuje všechny obrázky a funguje i po stažení bez internetu. Nevyžaduje instalaci ani sestavení.

GitHub Pages publikuje kořen větve `main`. Aktualizaci lze provést nahrazením `index.html` a vytvořením commitu. Slajd 2 obsahuje vygenerovanou rekonstrukci rozhraní ChatGPT z roku 2022.

Logo a podklady nejsou tímto repozitářem poskytovány pod otevřenou licencí.
